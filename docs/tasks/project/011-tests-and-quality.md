# Task 011 — Testes e Quality Gates

## Objective

Estabelecer validações automatizadas para evitar regressões.

## Depends On

* Tasks 003–010.

## Scope

Implementar ou revisar:

* Unit tests.
* Component tests.
* E2E tests quando necessários.
* Typecheck.
* Lint.
* Build.
* Broken-link checking.

## Acceptance Criteria

* [x] Testes relevantes implementados.
* [x] Typecheck passa.
* [x] Lint passa.
* [x] Build passa.
* [x] Links internos verificados.
* [x] Nenhum teste foi removido apenas para contornar falhas.
