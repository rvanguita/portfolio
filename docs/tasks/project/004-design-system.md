# Task 004 — Implementar Design System

## Objective

Criar a fundação visual utilizada pelos componentes da aplicação.

## Depends On

* Task 003.

## Scope

Implementar:

* Cores.
* Tipografia.
* Espaçamento.
* Radius.
* Shadows.
* Breakpoints.
* Transitions.
* Estados interativos.

## Requirements

O design deve ser:

* Moderno.
* Profissional.
* Minimalista.
* Responsivo.
* Acessível.

Evitar efeitos decorativos sem função.

## Acceptance Criteria

* [x] Tokens centralizados.
* [x] Tipografia definida.
* [x] Escala de espaçamento definida.
* [x] Breakpoints definidos.
* [x] Estados de interação definidos.
* [x] Contraste adequado.
* [x] `prefers-reduced-motion` considerado.
