# Task 005 — Migrar e Reescrever Conteúdo

## Objective

Migrar o conteúdo existente para a nova arquitetura e reescrevê-lo com linguagem técnica e profissional.

## Depends On

* Task 004.

## Scope

Reestruturar:

* Perfil.
* Sobre.
* Competências.
* Projetos.
* Experiência.
* Formação.
* Contato.

## Requirements

O conteúdo deve:

* Estar em pt-BR.
* Ser tecnicamente preciso.
* Ser objetivo.
* Priorizar resultados.
* Utilizar terminologia profissional.
* Ser adequado para recrutadores técnicos.

## Critical Constraint

Não inventar informações.

Quando uma informação não estiver disponível, manter placeholder explícito ou preservar a informação existente.

## Acceptance Criteria

* [x] Conteúdo existente foi revisado.
* [x] Conteúdo está separado da apresentação.
* [x] Textos estão em pt-BR.
* [x] Informações técnicas foram preservadas.
* [x] Informações não foram inventadas.
* [x] Projetos possuem estrutura consistente.
