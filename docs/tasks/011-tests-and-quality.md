# Task 011 — Testes e Quality Gates

## Objective

Estabelecer validações automatizadas para evitar regressões.

## Depends On

* Tasks 003–010.

## Scope

Implementar ou revisar:

* Unit tests.
* Component tests.
* E2E tests quando necessários.
* Typecheck.
* Lint.
* Build.
* Broken-link checking.

## Acceptance Criteria

* [ ] Testes relevantes implementados.
* [ ] Typecheck passa.
* [ ] Lint passa.
* [ ] Build passa.
* [ ] Links internos verificados.
* [ ] Nenhum teste foi removido apenas para contornar falhas.
