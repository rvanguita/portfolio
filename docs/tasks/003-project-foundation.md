# Task 003 — Criar Fundação do Projeto

## Objective

Estruturar a base técnica do novo projeto.

## Depends On

* Task 002.

## Scope

Implementar:

* Estrutura de diretórios.
* Configuração do framework.
* TypeScript, quando aplicável.
* Linter.
* Formatter.
* Test framework.
* Scripts de desenvolvimento.
* Scripts de build.

## Acceptance Criteria

* [x] Projeto inicia localmente.
* [x] Build funciona.
* [x] Lint funciona.
* [x] Testes funcionam.
* [x] Estrutura de diretórios segue o SDD.
* [x] Não existem dependências não utilizadas.

## Validation

Executar os comandos equivalentes a:

```text
install
lint
typecheck
test
build
```
