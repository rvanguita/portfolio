Engenharia de Dados

Estrutura das Camadas e Componentes

1. Ingestão & Raw Layer

Extração automatizada de dados de corridas, treinos livres, classificações e telemetria da Fórmula 1 utilizando a biblioteca FastF1, salvando os resultados brutos particionados em formato Parquet.

FastF1 Python Parquet AWS S3 Boto3

2. Bronze & Silver (Delta Lake)

Consolidação dos dados em tabelas Delta Lake na camada Bronze com versionamento ACID e criação da camada Silver curada com estatísticas agregadas de pilotos, construtores e histórico de voltas.

Delta Lake PySpark Pandas / NumPy ACID Transactions

3. Orquestração no Airflow

DAG programada para execução semanal com monitoramento de linhagem de dados (Asset), controle de concorrência e tarefas sequenciais com tolerância a falhas e espelhamento final para MySQL.

Apache Airflow DAGs MySQL / SQLAlchemy Data Lineage

4. MLOps, API & Dashboard

Modelo de Machine Learning para predição de campeonatos treinado com Scikit-Learn e rastreado no MLflow, exposto via API de baixa latência no FastAPI e painel analítico no Streamlit.

MLflow Scikit-Learn FastAPI Streamlit / Plotly
